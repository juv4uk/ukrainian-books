# ІНЖ-06 — контроль локальних Markdown-якорів

**Статус:** експериментальний офлайновий аудит. Завдання: [Issue #423](https://github.com/juv4uk/ukrainian-books/issues/423).

## Чому потрібен

Чинні перевірки посилань підтверджують існування локального файлу, але не встановлюють, чи веде фрагмент `#назва-розділу` до конкретного заголовка. Помилка може лишитися непоміченою у довідковому апараті бібліотеки.

Інструмент `scripts/check_markdown_fragments.py` читає лише локальні Markdown-документи, збирає орієнтовні ідентифікатори заголовків і зіставляє посилання у формі внутрішніх, міжфайлових та довідкових Markdown-посилань із фрагментами. Підтримано українські літери, URL-кодування, відносні шляхи, повторювані заголовки та базові ATX/Setext заголовки.

## Запуск

```sh
python3 -m unittest discover -s tests -p 'test_markdown_fragments.py' -v
python3 scripts/check_markdown_fragments.py
# Локальна діагностика з ненульовим кодом за наявності підозрілих якорів:
python3 scripts/check_markdown_fragments.py --strict
```

За замовчуванням знайдені невідповідності друкуються як **попередження**, а код завершення дорівнює нулю. Режим `--strict` призначений для локального розбору; його свідомо не підключено як обов'язковий CI-гейт. Окрема GitHub Actions перевірка виконує **блокувальні позитивні й негативні тести самого скрипта**, а потім спостережний аудит чинних документів.

## Межі доказовості

- Це **наближення** до обчислення якорів GitHub Markdown, а не повний CommonMark/GFM-рендерер; складна вкладена розмітка, HTML `id`, спеціальні форми посилань і нестандартні розширення можуть давати хибні сигнали.
- Лише локальні `.md`/`.markdown` цілі; зовнішні URL не перевіряються. Відсутні файли, небезпечні URL та undefined reference labels покривають інші валідатори.
- Ніяких мережевих запитів, філологічної оцінки санскриту, перевірки авторського права чи незалежного рецензування.
- Наявність чистого звіту не доводить правильності академічного посилання. Для переведення в обов'язковий `--strict` потрібні аналіз реальних попереджень, усунення відомих хибнопозитивних випадків і окреме незалежне технічне review.

Інструмент є власним технічним внеском під незміненою ліцензією «ВОЛЬНІСТЬ»; тексти джерельних цифрових корпусів сюди не переносилися.
