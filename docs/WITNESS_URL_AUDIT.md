# РЕД-04: офлайн-аудит адрес джерел

**Статус:** суто технічна перевірка, не санскритологічна, правова чи видавнича рецензія. Координація: [Issue #145](https://github.com/juv4uk/ukrainian-books/issues/145).

## Проблема

Чинний валідатор редакторських JSON-карток перевіряє HTTPS і локатор (наприклад, Avg_1.2 або verse_1.2), але може прийняти зовсім сторонній хост як нібито GRETIL або SARIT. Новий незалежний скрипт перевіряє **домен, репозиторій і конкретний шлях до твору**, не змінюючи схеми або іншого коду.

## Дозволені типи URL

| Джерело | Конкретний тип адреси | Межі впевненості |
| --- | --- | --- |
| GRETIL | gretil.uni-goettingen.de або www.gretil.uni-goettingen.de (також gretil.sub...), з шляхом до sa_aSTAvakragItA | Правильний домен і шлях не гарантують доступності |
| TextGrid | textgridrep.org/browse/49ks7.0 | Сталий ідентифікатор не є побайтовим SHA |
| Дзеркало GRETIL | tylergneill.github.io/gretil-mirror/.../sa_aSTAvakragItA.htm | Попередження: відповідність поточному офіційному джерелу не встановлена |
| Архів INDOLOGY | github.com/INDOLOGY/GRETIL-mirror/blob/REF/.../sa_aSTAvakragItA.xml або аналогічний raw URL | Попередження про дзеркало й рухомий ref |
| SARIT | github.com/sarit/SARIT-corpus/blob/REF/astavakragita.xml або аналогічний raw URL | Попередження про ref, який не є 40-символьним SHA |

Інструмент відхиляє сторонні репозиторії, підмінені домени, інші назви файлів, HTTP, URL із реквізитами авторизації, портами, query або fragment. Точні локатори й статуси перевіряє чинний скрипт check_editorial_cards.py.

**Не плутати:** перевірка правильної форми адреси не доводить, що файл існує саме зараз, що джерело містить зазначені слова, що цифрова транскрипція вільна від помилок, що дозволено її передрук або що переклад є академічно рецензованим. Цей скрипт не надсилає мережевих запитів і не переносить жодних санскритських текстів.

## Команди

Запускати з кореня репозиторію:

    python3 -m unittest discover -s tests -p 'test_witness_urls.py' -v
    python3 scripts/audit_witness_urls.py
    python3 scripts/check_editorial_cards.py
    python3 scripts/check_project.py

Результат audit_witness_urls.py — JSON зі станом ok/failed, числом прочитаних карток, масивом помилок і **окремим масивом попереджень**. Хибні URL спричиняють ненульовий exit; дзеркало і рухомий ref залишаються видимими попередженнями. Відсутній каталог чесно дає cards=0, а не «всі 298 віршів перевірено». Workflow witness-urls.yml перевіряє pull_request і push до main.

**Ліцензія:** власний код і документація — за незмінною «ВОЛЬНІСТЮ». Жодного стороннього цифрового корпусу, чужого перекладу чи коментаря не додано.
