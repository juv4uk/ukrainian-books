# ГЕН-01 — структуроване построкове вирівнювання наукових глав

## Для чого

Чинний п'ятишаровий формат переважно оформлено **за цілими віршами**, а власникові потрібна послідовність **кожен друкований санскритський рядок → деванагарі → IAST → українське звучання → український відповідник → граматичний і науковий коментар**. Окремі чернетки `editorial/scholarly-drafts/` самі собою не входять у канонічний генератор. Цей контракт дає їм структурований шлях до Markdown і LaTeX без автоматичного прийняття спірних трактувань.

## Джерело істини

Власний текст вірша, IAST, цілісний український переклад і науковий коментар залишаються в `editorial/cards/N.M.json`. Порозділові додаткові дані вже лежать у `books/ashtavakra-gita/format-v2/rozdil-N.json`. Опційне поле `postrokovo` в записі конкретного вірша має такий формат:

```json
{
  "verses": {
    "5.1": {
      "postrokovo": {
        "status": "чернетка",
        "lines": [
          {
            "iast": "na te saṅgo 'sti kenāpi kiṃ śuddhas tyaktum icchasi",
            "ukrainian_translation": "У тебе немає зв'язку ні з чим — то чого ж ти, чистий, хочеш відкинути?",
            "commentary": "Питальна конструкція ставить під сумнів потребу відкидати те, до чого зв'язку немає."
          },
          {
            "iast": "saṅghātavilayaṃ kurvann evam eva layaṃ vraja",
            "ukrainian_translation": "Здійснюючи розчинення скупчення, так само йди до розчинення.",
            "commentary": "Дієприкметник і наказова форма утворюють другу половину вірша; тлумачення laya потребує рецензування."
          }
        ]
      }
    }
  }
}
```

Це **приклад схеми**, а не внесення непогодженого поля в живу картку. Першу міграцію слід оформити окремим PR після редакторського CLAIM, з перевіркою обох фрагментів та збереженням наявної поетичної глави.

## Перевірки

- Допускаються лише два друковані санскритські піврядки; **не видавати це за автоматично визначені чотири метричні пади**. Підтримка чотирьох пад — окреме редакторське розширення, не бездоказовий машинний поділ.
- IAST кожного рядка дослівно, з нормалізацією лише пробілів, збігається з відповідною половиною `iast` картки, відокремленою `|` та `||`. Інакше збірка має завершитися помилкою.
- Обидва українські фрагменти при сполученні одним пробілом **дослівно** відтворюють `ukrainian_translation` картки. Не підміняти її новою робочою редакцією.
- Коментар кожного рядка обов'язковий. Деванагарі та українська практична передача створюються **механічно** з перевіреного IAST цієї картки; це не незалежна санскритська колація.
- Дозволений тільки `status: чернетка`. Не проголошувати дані рецензованими без незалежного документованого огляду та правової підстави.
- За відсутності `postrokovo` вихід існуючих 298 карток **не змінюється**: старі Markdown/LaTeX виходи лишаються сумісними. Зміна основних даних окремої глави вимагає відтворюваної перегенерації саме цієї глави, перевірки diff та CI; не робити сліпу масову перегенерацію чужих редакторських шарів.

## Використання

`scripts/build_format_v2_chapter.py` читає `postrokovo` через `scripts/postrokove.py` і за наявності додає до Markdown та LaTeX два явно позначені **нерецензовані** редакторські рядки. Відповідно до правил безпечного приймання це **інфраструктура**, а не готова академічна книга. Звіти про готовність мають окремо рахувати зібрані й незалежно рецензовані рядки. Повний поетичний переклад залишається самостійним томом.
