# Звіт охоплення редакторських карток

Інструмент `scripts/report_card_coverage.py` — **офлайновий лічильник**, а не наукова експертиза. Він читає чинний [реєстр 20 глав](../research/ashtavakra/registry-20-chapters.csv) і тільки реальні JSON-картки з `editorial/cards/`. Структура та обмеження статусів перевіряються функціями з [існуючого валідатора](../scripts/check_editorial_cards.py); жодного другого нормативного валідатора не створюється.

Запуск з кореня репозиторію:

```sh
python3 scripts/report_card_coverage.py
python3 -m unittest discover -s tests -p 'test_report_card_coverage.py' -v
```

Стандартний вивід — UTF-8 JSON із полями `стан`, `застереження`, `підсумок`, `глави` й `помилки`. Для кожної із 20 глав показано очікувані позиції, кількість валідних карток, прогалини й розподіл **заявлених у самих JSON** статусів `чернетка`, `перевірено`, `рецензовано`. Позиції на кшталт 18.95 не губляться через особливості XML-розмітки SARIT, адже використовується канонічний реєстр. Відсутня картка — нормальна прогалина; некоректний файл, дубль ID, symlink або невідомий номер — помилка з ненульовим кодом завершення. Файли не змінюються, звіт не записується в дерево, мережа не використовується.

**Межа інтерпретації:** статус `перевірено` означає, що редактор *заявив* авторську звірку у картці, а `рецензовано` — наявність полів, які пройшли технічний валідатор. Лічильник **не доводить** справжність незалежної рецензії, достовірність санскриту, повноту текстологічної роботи чи правомірність публікації. Тому статистику не можна називати «стільки-то науково перевірених віршів» без окремих доказів.

Цей звіт — додаток до ручних зведень для рецензента, не їх заміна. Він не копіює текст GRETIL, SARIT, сучасних перекладів або сторонніх коментарів і не змінює ліцензію «ВОЛЬНІСТЬ».
