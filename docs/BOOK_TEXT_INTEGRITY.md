# РЕД-05: технічна цілісність книжкових текстів

Мета — зупинити пошкоджені українські файли **до** верстки. Це окремий програмний контроль, **не** санскритологічна, редакторська, орфографічна чи правова рецензія.

## Команди

```sh
python3 -m unittest discover -s tests -p 'test_book_text_integrity.py' -v
python3 scripts/check_book_text_integrity.py
python3 scripts/check_project.py
```

Перевіряються лише текстові файли всередині `books/` із розширеннями `.tex`, `.md`, `.bib`, `.sty`, `.cls`, `.txt`, включно з паспортом `PROVENANCE.md`. Скрипт не читає PDF/EPUB, не завантажує сторонні джерела й не слідує символічними посиланнями. Якщо `books/` не існує, він явно звітує **0 перевірених файлів**; це не доказ готовності видань.

## Що вважається технічним дефектом

- Символ заміни **U+FFFD** (`�`) та недійсні байти UTF-8.
- Недопустимі керувальні символи, приховані керувальні коди напрямку письма та деякі невидимі символи, що можуть змінювати відображення.
- Діакритичні знаки з арабської або єврейської писемності, випадково приєднані до кириличних чи латинських літер, наприклад `т֖лі` (U+0596). **Справжні** слова арабською або івритом із власними знаками не відхиляються автоматично.

Українські наголоси, латинські знаки IAST та звичайний санскрит деванагарі допускаються. Гранична кількість повідомлень з одного файла — 25, щоб не перевантажувати лог.

## Чого перевірка не гарантує

Пошкодження без технічних маркерів — наприклад `двадчять` чи `Чк` замість правильної української форми — **не буде виявлено**. Такі помилки вимагають людської вичитки. Також потрібні окремі джерелознавче рецензування, юридичне підтвердження прав та чинний суворий `check_provenance.py` перед випуском PDF.

Спонуканням до контрольного тесту був [незлитий PR #94](https://github.com/juv4uk/ukrainian-books/pull/94), де у Git blob наявні U+FFFD і U+0596. Цей PR не змінено. Нові тести використовують **лише синтетичні рядки**, не копії сторонніх видань.

Власний код і ця документація підпорядковані чинній «ВОЛЬНІСТЬ» лише в межах належних нам прав. Тексти `LICENSE` і `VOLNOST.md` не змінювалися.
