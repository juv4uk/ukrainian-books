# РЕД-05: технічна цілісність книжкових текстів

Мета — зупинити пошкоджені українські файли **до** верстки. Це окремий програмний контроль, **не** санскритологічна, редакторська, орфографічна чи правова рецензія.

## Команди

```sh
python3 -m unittest discover -s tests -p 'test_book_text_integrity.py' -v
python3 scripts/check_book_text_integrity.py
python3 scripts/check_project.py
```

Перевіряються три обсяги (звірено 31.10.2026):

- `books/**` — текстові файли з розширеннями `.tex`, `.md`, `.bib`, `.sty`, `.cls`, `.txt`, включно з паспортом `PROVENANCE.md`;
- `editorial/cards/*.json` — редакторські картки;
- `research/**/*.md` — дослідницькі примітки.

Скрипт не читає PDF/EPUB, не завантажує сторонні джерела й не слідує символічними посиланнями. Якщо якогось обсягу не існує, він явно звітує **0 перевірених файлів** у цьому обсязі; це не доказ готовності видань. Підсумковий звіт містить `scanned_files` (разом) і `scanned_by_scope` (окремо `books`, `cards`, `research`).

**Чому обсяг розширено.** До 31.10.2026 перевірка дивилася лише в `books/`, тому в `editorial/cards/2.2.json` роками жив дефект: «свіЂ» замість «світ» (U+0402), «Аштавакрааёіти» замість «Аштавакра-ґіти» (U+0451), «надбанні.Ритання» замість «надбанні. Читання». CI був зелений весь час. Сам дефект виправлено в PR #216, але без розширення обсягу наступний такий випадок знову пройшов би повз гейт.

## Що вважається технічним дефектом

- Символ заміни **U+FFFD** (`�`) та недійсні байти UTF-8.
- Недопустимі керувальні символи, приховані керувальні коди напрямку письма та деякі невидимі символи, що можуть змінювати відображення.
- Діакритичні знаки з арабської або єврейської писемності, випадково приєднані до кириличних чи латинських літер, наприклад `т֖лі` (U+0596). **Справжні** слова арабською або івритом із власними знаками не відхиляються автоматично.
- Кириличні літери, яких немає в українській абетці: `ы э ъ ё Ђ` тощо (33 літери української абетки — єдиний дозволений набір).
- Латиниця всередині кириличного слова: `свiт` із латинською `i`, `світl`. Дефіс, пробіл, цифра чи розділовий знак розривають слово, тому `dvandva-складений` і `bahuvrīhi-складник` — **не** дефект. Латинські літери з гострим наголосом (`á é í ó ú ý`) усередині кириличного слова теж **не** дефект: це усталений спосіб позначити український наголос, коли прекомпонованої кириличної літери немає (`самóю`).
- Подвійний пробіл усередині тексту (картки й примітки). Відступ на початку рядка, подвійний пробіл у кінці рядка (у Markdown це жорсткий перевід рядка), вирівнювання в таблицях Markdown і код у блоках ```` ``` ```` не вважаються дефектом.
- Втрачений пробіл після крапки перед великою кириличною літерою: `надбанні.Ритання`.

Українські наголоси, латинські знаки IAST (`ā ī ū ṛ ṃ ḥ ś ṣ ṭ ḍ ṇ ñ`) та звичайний санскрит деванагарі допускаються — вони не мішають писемностей усередині одного слова. «Прозові» правила (подвійний пробіл, втрачений пробіл після крапки) застосовуються лише до карток і приміток, не до `books/**`: верстка `.tex` законно містить вирівнювання, і гейт, який валить законні файли, вимикають швидше, ніж він щось ловить. Гранична кількість повідомлень з одного файла — 25, щоб не перевантажувати лог.

## Чого перевірка не гарантує

Пошкодження без технічних маркерів — наприклад `двадчять` чи `Чк` замість правильної української форми — **не буде виявлено**. Такі помилки вимагають людської вичитки. Також потрібні окремі джерелознавче рецензування, юридичне підтвердження прав та чинний суворий `check_provenance.py` перед випуском PDF.

Спонуканням до контрольного тесту був [незлитий PR #94](https://github.com/juv4uk/ukrainian-books/pull/94), де у Git blob наявні U+FFFD і U+0596. Цей PR не змінено. Нові тести використовують **лише синтетичні рядки**, не копії сторонніх видань.

Власний код і ця документація підпорядковані чинній «ВОЛЬНІСТЬ» лише в межах належних нам прав. Тексти `LICENSE` і `VOLNOST.md` не змінювалися.
