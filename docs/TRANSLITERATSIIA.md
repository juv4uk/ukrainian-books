# Українська транслітерація IAST: таблиця відповідностей

**Статус:** робочий редакційний документ, не наукова транскрипція.
**Виконувана частина:** `scripts/iast_to_ukrainian.py`.
**Тести:** `tests/test_iast_to_ukrainian.py`.

## Для чого цей шар

Читач книги бачить санскритський рядок у трьох виглядах: деванагарі
(письмо), українська транслітерація (звучання українськими літерами) і
переклад. Транслітерація не є перекладом і не є науковою фонетичною
транскрипцією: її єдина робота — дати людині, яка не знає латинської
діакритики, **вимовити** рядок уголос і почути, що він повторюється
(рефрени глав 5 і 6 тримаються саме на повторі).

Тому тут свідомо **немає** позначок довготи, наголосу, тону й складових меж.
Усе, що втрачено, перелічено в розділі «Що втрачено» — і кожна втрата
названа прямо, а не замовчана.

## Принципи

1. **Одна латинська літера — одна кирилична.** Де це неможливо, відповідник
   дволітерний, і він у таблиці явно.
2. **Довгота не передається.** `ā ī ū` → `а і у`. Українська не розрізняє
   довгих і коротких голосних; діакритика в кирилиці читалася б як наголос,
   а наголос у санскриті інший.
3. **Придих передається фрикативним.** Це головне рішення всієї системи
   (див. нижче).
4. **Невідомий символ — помилка, не пропуск.** Конвертер піднімає виняток і
   називає позицію. Тихого пропуску немає навмисно.
5. **Данди й пробіли зберігаються точно.** `|` і `||` позначають межі
   піввіршів; транслітерація не має права переставляти структуру рядка.

## Таблиця: приголосні

| IAST | Кирилиця | Обґрунтування |
|---|---|---|
| `k` | к | пряма відповідність |
| `kh` | кх | придих після глухого лишається глухим: [kʰ] → «кх» |
| `g` | ґ | українське «ґ» — проривний [g], тобто санскритське `g`; так `g` не зливається з `h` |
| `gh` | ґг | придих після дзвінкого озвучується; українське «г» — фрикативний [ɣ], найближчий до озвученого придиху. Дає усталене «Бгаґавадґіта» |
| `ṅ` | н | велярний носовий; окремої літери немає, а «нґ» подвоювало б приголосний там, де його немає |
| `c` | ч | санскритське `c` — глухий піднебінний африкат [t͡ɕ], найближче українське «ч» |
| `ch` | чч | **правило власника**; подвоєння відрізняє придиховий `ch` від `c`. Свідомо відступає від схеми «придих через х/г» — інакше «чх» читалося б як два звуки |
| `j` | дж | дзвінкий відповідник `c` |
| `jh` | джг | придих після дзвінкого, за загальним правилом |
| `ñ` | нь | піднебінний носовий [ɲ]; «нь» — єдиний український відповідник |
| `ṭ` | т | ретрофлексний [ʈ]; окремої літери немає, злиття з `t` названо у «Що втрачено» |
| `ṭh` | тх | придих після глухого |
| `ḍ` | д | ретрофлексний [ɖ] |
| `ḍh` | дг | придих після дзвінкого |
| `ṇ` | н | ретрофлексний [ɳ] |
| `t` | т | зубний [t̪] |
| `th` | тх | придих після глухого; дає усталене «катха» |
| `d` | д | зубний [d̪] |
| `dh` | дг | придих після дзвінкого; дає усталене «дгарма», «Будга» |
| `n` | н | зубний [n̪] |
| `p` | п | пряма відповідність |
| `ph` | пх | придих після глухого |
| `b` | б | пряма відповідність |
| `bh` | бг | придих після дзвінкого |
| `m` | м | пряма відповідність |
| `y` | й | напівголосний [j] |
| `r` | р | пряма відповідність |
| `l` | л | пряма відповідність |
| `v` | в | напівголосний [ʋ]; «в» — найближчий український звук |
| `ś` | ш | **правило власника**; [ɕ] → «ш» |
| `ṣ` | ш | **правило власника**; ретрофлексний [ʂ] зливається з `ś` |
| `s` | с | пряма відповідність |
| `h` | х | просте `h` — глухий [h]; «х» дає усталене «Брахман» |

### Чому придих — то «х», то «г»

Це не непослідовність, а одне правило, застосоване двічі:

* після **глухого** приголосного придих лишається глухим → «**х**»:
  `kh` → кх, `th` → тх, `ph` → пх;
* після **дзвінкого** приголосного придих озвучується → «**г**»:
  `gh` → ґг, `jh` → джг, `ḍh` → дг, `dh` → дг, `bh` → бг.

Саме так уже пишуть українською: **Бгаґавадґіта**, **дгарма**, **Будга**,
**Сіддгартха**, але **катха**, **кхандга**. Виняток один — `ch` → **чч**,
заданий власником.

## Таблиця: голосні

| IAST | Кирилиця | Обґрунтування |
|---|---|---|
| `a` | а | коротке [ɐ] |
| `ā` | а | довгота не передається (принцип 2) |
| `i` | і | коротке [i] |
| `ī` | і | довгота не передається |
| `u` | у | коротке [u] |
| `ū` | у | довгота не передається |
| `e` | е | [eː]; в українській «е» — це [e] |
| `ai` | ай | дифтонг [ai̯] |
| `o` | о | [oː] |
| `au` | ау | дифтонг [au̯] |

### Складотворчі плавні `ṛ` `ṝ` `ḷ` `ḹ`

`ṛ` → **рі** або **ри** — за одним перевірним правилом: якщо в цьому слові
після складотворчого є ще голосний, склад відкритий і пишемо **рі**;
якщо складотворчий стоїть у кінці слова — **ри**.

| IAST | Кирилиця | Чому |
|---|---|---|
| `kṛṣṇa` | крішнам | далі є голосний → «рі»; усталене «Крішна» |
| `ṛṣi` | ріші | те саме |
| `kṛta` | крітам | те саме |
| `pitṛ` | питри | складотворчий у кінці слова → «ри» |
| `mātṛ` | матри | те саме |

`ḷ` і `ḹ` обробляються так само з «л» → **лі** / **ли**. У корпусі
«Аштавакра-ґіти» вони не трапляються (перевірено прогоном по всіх картках),
але правило є, щоб конвертер не падав на інших текстах.

## Таблиця: надрядкові знаки й аваґраха

| IAST | Кирилиця | Обґрунтування |
|---|---|---|
| `ṃ` | м | **правило власника**; анусвара перед приголосним асимілюється, але ми пишемо «м» завжди — інакше довелося б вигадувати правило асиміляції, якого немає у вході |
| `ṁ` | м | варіант запису анусвари (крапка над `m`) |
| `ḥ` | х | **правило власника**; вісарґа — глухий придих |
| `'` `ʼ` `’` | ’ | аваґраха (випале `a`); зберігаємо як апостроф, бо він позначає межу слів |

## Таблиця: розділові знаки

| IAST | Кирилиця |
|---|---|
| `\|` | `\|` (без змін) |
| `\|\|` | `\|\|` (без змін) |
| пробіл, переніс рядка, табуляція | без змін |
| `. , ; : ! ? - – — ( ) [ ] { } « » … / * + =` | без змін |

Данди не перетворюються на `।`/`॥` у **цьому** шарі: це український текст,
і санскритський розділовий знак тут був би чужим. Данди перетворюються лише
в шарі деванагарі (`scripts/iast_to_devanagari.py`).

## Орфографічні дрібниці української

* **М'якість.** Після `ñ` (→ «нь») голосний пишеться йотованою літерою, а
  «ь» зникає: `jñāna` → **джняна** (не «джньяна»), `jñeya` → **джнєя**.
* **Йотація.** `y` перед голосним дає йотовану літеру: `yathā` → **ятха**,
  `yoga` → **йоґа**, `satya` → **сатя**, `kāya` → **кая**.
* **Апостроф.** Після **б п в м ф р** перед `я є ї ю` ставимо апостроф, як
  вимагає українська орфографія: `rūpya` → **руп'я**, `kāvya` → **кав'я**.

## Що втрачено (названо прямо)

| Втрата | Наслідок | Де компенсується |
|---|---|---|
| Довгота `ā ī ū` | не видно, чи голосний довгий | шар IAST і шар деванагарі в книзі |
| Ретрофлексність `ṭ ḍ ṇ ṣ` | `т`=`ṭ`, `д`=`ḍ`, `н`=`ṇ`, `ш`=`ś`/`ṣ` | шари IAST і деванагарі |
| Різниця `ś` / `ṣ` | обидва «ш» | шари IAST і деванагарі |
| Різниця `h` / `ḥ` | обидва «х» | шари IAST і деванагарі |
| Тон і наголос ведичного читання | не передаються взагалі | ніде; це поза межами видання |
| Складові межі | не позначені | поетичний переклад показує ритм |

Жодна з цих втрат не є мовчазною: усі вони названі тут, і всі вони
компенсуються тим, що читач бачить IAST і деванагарі поруч із транслітерацією.

## Як перевірити

```sh
python3 scripts/iast_to_ukrainian.py 'kathaṃ jñānam avāpnoti'
python3 scripts/iast_to_ukrainian.py --cards      # прогін по всіх картках
python3 -m unittest discover -s tests -p 'test_iast_to_ukrainian.py' -v
```

Прогін `--cards` на 2026-11-01: 249 карток із 253 мають поле `iast`;
4 картки (15.2, 4.3, 4.4, 4.5) поля не мають — це прогалина в даних, а не
збій конвертера, і вона названа у звіті.
