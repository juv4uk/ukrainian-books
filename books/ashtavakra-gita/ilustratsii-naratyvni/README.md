# Наративні ілюстрації до віршів

**Це наші власні малюнки. Вони не є історичними ілюстраціями.**

Схеми в `../ilustratsii/` пояснюють **поняття** (свідок, ілюзія,
простір, вузол). Тут — **сцени**: що саме відбувається у вірші. Двоє
сидять і розмовляють; людина відсахнулася від мотузки; човен блукає
океаном; слон обходить гірке листя.

Фігури — силуети без облич. Це зроблено свідомо: обличчя перетворило б
малюнок на претензію зобразити конкретну людину, а ми не маємо жодного
зображення, на яке могли б спертися. Тому тут немає ні портретів, ні
одягу з претензією на давність, ні орнаменту.

Палітра й лінія — ті самі, що в схемах: папір, графіт, вохра, тонкий
контур. Кожен файл несе напис «Наша ілюстрація до вірша N.N — не
історичне зображення», щоб його неможливо було видати за джерело,
навіть вирвавши з книги.

Відібрано не всі 298 віршів, а ті, де є справжня сцена або образ:
розмова, предмет, рух, тварина. Вірші без сцени лишилися зі схемою —
малювати до них «щось» означало б вигадувати те, чого в тексті немає.

## Як це зроблено

Файли генерує `scripts/build_narrative_scenes.py`: кожна сцена —
функція з примітивів (силует, глечик, човен, слон). Реєстр для книги —
`../format-v2/scenes.json`.

```sh
python3 scripts/build_narrative_scenes.py          # SVG
python3 scripts/build_narrative_scenes.py --check  # чи не застаріли
```
