# Схеми до віршів

**Це наші власні векторні схеми. Вони не є історичними ілюстраціями.**

Жодна з них не є репродукцією, сканом, фотографією чи чужим малюнком.
Кожна пояснює будову вірша — рух думки, ключову метафору, структуру
повтору — і не претендує на те, щоб виглядати «давньою».

Стиль навмисно стриманий: лінія, геометрія, палітра паперу й вохри.
Це ближче до української книжкової графіки, ніж до «східної» бутафорії,
і саме тому тут немає ні орнаменту, ні стилізації під мініатюру.

Кожен файл містить напис «Схема наша, не історична ілюстрація» — щоб
його неможливо було видати за джерело, навіть вирвавши з книги.

## Як це зроблено

Файли генерує `scripts/build_verse_schemas.py` з параметричних мотивів.
Мотив — це функція, яка малює схему за параметрами (підписи, варіант
образу). Тому машина працює і для решти віршів: досить додати запис
у `SPECS`. PDF-версії для верстки — `--pdf` (потрібен `cairosvg`).

```sh
python3 scripts/build_verse_schemas.py          # SVG
python3 scripts/build_verse_schemas.py --pdf    # ще й PDF для XeLaTeX
python3 scripts/build_verse_schemas.py --check  # чи не застаріли
```
