# Робоче пілотне видання «Аштавакра-ґіти»

**Це не книга.** Це робоче пілотне видання, яке доводить, що верстальна машина
репозиторію справді складає український PDF із кирилицею та діакритикою IAST.
Джерело тексту — власні редакторські картки зі статусом **«чернетка»**.

| Що | Значення |
| --- | --- |
| Зверстано | глави 2 і 3 — 39 віршів (25 із 25 та 14 із 14 за реєстром) |
| Джерело | `editorial/cards/*.json`, лише власні поля карток |
| Формат | A5, 10 pt, DejaVu Serif, XeLaTeX |
| Статус карток | «чернетка» — усі, без винятків |
| Рецензія | немає |
| Правова підстава | власний внесок під «ВОЛЬНІСТЮ»; див. [PROVENANCE.md](PROVENANCE.md) |

## Що саме зверстано

Для кожного вірша — український переклад, дослівне значення, граматичний розбір,
філософський коментар і примітки про різночитання. Плюс апарат: покажчик термінів
(makeindex), редакційний словник і розділ про межі видання.

## Чого тут свідомо немає

Санскритського тексту віршів. Поля `sanskrit` і `iast` у картках відтворюють
читання цифрових транскрипцій GRETIL (CC BY-NC-SA 4.0) і SARIT (CC BY-SA 3.0).
Паспорт джерела дозволяє PDF лише для нашого власного внеску, тому в пілоті
залишено **покажчик** на свідка (локатор `Avg_2.1` / `verse_2.1`), а не його
текст. Генератор фізично не читає ці поля — див.
`WITNESS_FIELDS` у `scripts/build_pilot_book.py`.

## Складання

```sh
# 1. Згенерувати LaTeX із карток
python3 scripts/build_pilot_book.py

# 2. Скласти PDF (з кореня репозиторію)
cd books/ashtavakra-hita-pilot
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

Без `latexmk`:

```sh
xelatex main.tex && makeindex main.idx && xelatex main.tex && xelatex main.tex
```

Потрібні пакети: `texlive-xetex`, `texlive-lang-cyrillic`, `texlive-latex-recommended`,
`texlive-fonts-recommended`, `fonts-dejavu-core`, `latexmk`. Шрифт — DejaVu Serif.

У GitHub Actions це робить наявний workflow `build-books.yml` — **вручну**
(`workflow_dispatch`), не на кожен push. Він спершу проганяє
`scripts/check_project.py` і `scripts/check_provenance.py`, і лише якщо паспорт
походження повний — складає PDF і прикріплює його як артефакт.

## Структура

```
main.tex                      шаблон видання: титул, вихідні дані, передмова,
                              розділи, апарат, покажчик
PROVENANCE.md                 паспорт походження (12 полів, статус прав)
generated/verses.tex          ЗГЕНЕРОВАНО з карток — не редагувати вручну
generated/glossary.tex        ЗГЕНЕРОВАНО з editorial/GLOSSARY.md
generated/manifest.json       склад пілота: які картки, які статуси
```

`generated/` — похідні файли. Правити треба картки або
`scripts/build_pilot_book.py`, а потім перегенерувати. Перевірити, чи згенероване
не застаріло:

```sh
python3 scripts/build_pilot_book.py --check
```

## Чому саме глави 2 і 3

Це єдині глави, де картки покривають усі вірші реєстру без пропусків. В інших
главах покриття часткове: у главі 18 це 67 карток на 100 віршів, у главі 1 — 9 на
20, глав 16, 17 і 20 немає зовсім. Детальна таблиця готовності — у видавничому
висновку `docs/VYDAVNYCHYI_VYSNOVOK.md`.
