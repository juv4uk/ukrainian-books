# ДРУК-01 — відтворювана проба трьох писемних шарів

Це **технічний офлайновий тест верстки**, не текст «Аштавакра-ґіти» й не дозвіл на публікацію. Слова `आत्मा`, `ज्ञानम्`, `साक्षिन्` — загальні санскритські лексеми, обрані тільки для перевірки складених символів, матр і приголосних. Українські відповідники у пробі — **незатверджені читальні приклади**, не нормативний словник чи переклад вірша.

## Навіщо

Чинна [верстальна машина](../../docs/BOOK_PDF_MACHINE.md) перевіряє українську кирилицю та IAST через `DejaVu Serif`, проте цього недостатньо для деванагарі. Новий редакційний формат із [Issue #553](https://github.com/juv4uk/ukrainian-books/issues/553) та [PR #552](https://github.com/juv4uk/ukrainian-books/pull/552) потребує **окремого шрифту для індійського письма**. У цьому зразку використано `Noto Serif Devanagari` для деванагарі, `DejaVu Serif` для української та IAST. Файли шрифтів до репозиторію не додаються.

## Відтворення

Потрібні `xelatex`, пакети `fontspec`, `polyglossia`, `geometry`, мовні правила української та встановлені системні шрифти `Noto Serif Devanagari` і `DejaVu Serif`.

```sh
cd research/typesetting-devanagari
fc-match 'Noto Serif Devanagari'
xelatex -interaction=nonstopmode -halt-on-error -file-line-error proof.tex
pdfinfo proof.pdf | grep '^Pages:'
grep -n 'Missing character' proof.log || true
pdftotext -enc UTF-8 proof.pdf -
```

Після складання обов'язково **відкрити або растеризувати** PDF та візуально перевірити послідовності знаків деванагарі. Файл `proof.pdf` і допоміжні `.aux` / `.log` — локальні результати, **їх не комітити**.

## Виміряний локальний результат, 31.10.2026

- Реальний XeLaTeX: **exit code 0**, одна сторінка A4, читабельна українська та IAST.
- `Noto Serif Devanagari` наявний у середовищі; повідомлень `Missing character` у журналі немає.
- PDF візуально переглянуто як растрове зображення: три санскритські словоформи відображені.
- **Відоме обмеження:** `pdftotext` може переставити комбінувальні знаки деванагарі під час витягання, навіть якщо вигляд PDF правильний (у цій пробі це трапляється для третього слова). Тому **текстовий grep сам не доводить правильність відображення**. Для реального видання потрібні візуальний контроль і, де це можливо, семантична звірка з рецензованим джерельним текстом.

## Межі приймання

Тест **не** підтверджує точність конвертації IAST → деванагарі, української читальної транскрипції, рецензію, авторські права чи готовність книжки. Для публікації потрібні окремі правова підстава на відтворення конкретного санскритського тексту, незалежна редакторська перевірка і позитивний `scripts/check_provenance.py`. Не змінювати для цього існуючі видавничі гейти; інтеграція шрифту у книжковий шаблон має бути окремим перевіреним PR.
