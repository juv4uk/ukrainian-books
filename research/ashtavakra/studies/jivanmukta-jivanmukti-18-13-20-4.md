# ДОСЛ-10: `jīvanmukta` і `jīvanmukti` — чотири засвідчені місця

**Статус:** авторська дослідницька примітка, **не** незалежна філологічна рецензія і **не** критичне видання.  
**Дата звірки цифрових джерел:** 31.10.2026.  
**Завдання:** [Issue #400](https://github.com/juv4uk/ukrainian-books/issues/400).

## Чому це потрібно

У вже злитій [картці 18.13](../../../editorial/cards/18.13.json) після [PR #366](https://github.com/juv4uk/ukrainian-books/pull/366) сказано, що `jīvanmukta` «єдиний раз у книзі з'являється саме тут». Пошук за одним точним написанням не можна ототожнювати з пошуком леми у відмінюваних санскритських формах. Конкретне твердження про єдине місце **спростовують** `jīvanmuktasya` у 18.13 та `jīvanmuktaḥ` у **18.26**. Пов'язаний іменник `jīvanmukti` трапляється ще у 18.80 і 20.4. Ці слова морфологічно споріднені, але **не тотожні леми**.

Наявний авторський запис 18.13 тут **не виправляється напряму**: це окрема дослідницька довідка для майбутнього редакторського рішення. Чернетку 20.4 готують у [Issue #370 / PR #377](https://github.com/juv4uk/ukrainian-books/pull/377), без втручання в його CLAIM.

## Чотири контексти

| Вірш | SARIT: потрібна коротка форма | GRETIL: відповідна форма | Власний граматичний висновок |
| --- | --- | --- | --- |
| **18.13** | `jīvanmuktasya` | `jīvanmuktasya` | Родовий однини чоловічого роду від **`jīvanmukta`**, означає «того, хто звільнений за життя»; узгоджується з `yoginaḥ` |
| **18.26** | `jīvanmuktaḥ` | `jīvanmuktaḥ` | Називний однини чоловічого роду від **`jīvanmukta`**; ще одна пряма згадка звільненої за життя особи |
| **18.80** | `jīvanmuktirna` | `jīvanmuktir na` | Сандгі **`jīvanmuktiḥ + na`**; іменник жіночого роду «звільнення за життя» у заперечній риторичній побудові |
| **20.4** | `jīvanmuktirapi` | `jīvanmuktir api` | Сандгі **`jīvanmuktiḥ + api`**; той самий іменник у риторичному запитанні `kva ... kva vā` |

Пробіл між `jīvanmuktir` та `na` або `api` — відмінність **сегментації електронного запису**, а не доведене змістове різночитання. Граматичні висновки тут авторські та потребують незалежної санскритологічної перевірки.

Отже, у двох перевірених цифрових свідках за віршовими XML-ID зафіксовано **щонайменше дві появи леми `jīvanmukta` (18.13, 18.26)** і **дві появи спорідненого іменника `jīvanmukti` (18.80, 20.4)**. Це не чотири появи однієї й тієї самої леми. Не слід рахувати додаткові GRETIL-блоки `note type="analysis"` як нові вірші: вони пояснюють ті самі місця.

## Відтворюваний контроль SARIT

Після отримання **саме пінованого** `astavakragita.xml` під назвою `/tmp/astavakragita.xml` перевірку можна виконати стандартним Python без додаткових бібліотек:

```python
from pathlib import Path
from xml.etree import ElementTree as ET
import re

path = Path("/tmp/astavakragita.xml")
root = ET.parse(path).getroot()
tei = "{http://www.tei-c.org/ns/1.0}"
xml_id = "{http://www.w3.org/XML/1998/namespace}id"
hits = []
for lg in root.iter(tei + "lg"):
    verse = lg.get(xml_id, "")
    if not verse.startswith("verse_"):
        continue
    text = " ".join(lg.itertext())
    forms = re.findall(r"\bjīvanmukt\w*", text, flags=re.IGNORECASE)
    if forms:
        hits.append((verse.removeprefix("verse_"), forms))
print(hits)
assert [verse for verse, _ in hits] == ["18.13", "18.26", "18.80", "20.4"]
```

**Обмеження методу:** це пошук конкретної графічної основи `jīvanmukt-` у зазначеній транскрипції, а не автоматична лематизація всього санскриту. Інші написання, редакції та рукописи цим не перевірено. Для GRETIL слід читати основні `lg[@xml:id]`, не повторно рахувати редакторські `note`.

## Рекомендація редакції

- У майбутньому виправленні [картки 18.13](../../../editorial/cards/18.13.json) замінити «єдиний раз» на обережне твердження: «`jīvanmukta` стоїть у 18.13 та 18.26; споріднений іменник `jīvanmukti` — у 18.80 та 20.4 (за SARIT і GRETIL)».
- Перед піднесенням картки до статусу `перевірено` незалежно оцінити вірш 18.26 та філософський контекст заперечень у 18.80 і 20.4. Наявність чотирьох форм не означає тотожності висловлених у них тез.
- Не замінювати власне дослідження зовнішнім сучасним перекладом. Не приписувати сучасному цифровому свідку статусу історичного критичного видання.
