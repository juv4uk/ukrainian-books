# ДОСЛ-13: чому пошук «varṇa» плутає соціальну категорію із золотом

**Статус:** авторська дослідницька примітка; не незалежне рецензування, не критичне видання.  
**Дата електронної звірки:** 31.10.2026.  
**Завдання та зона роботи:** [Issue #443](https://github.com/juv4uk/ukrainian-books/issues/443), тільки цей файл.

## Питання і перевірений результат

Чи означає збіг підрядка `varṇ` у двох віршах, що «Аштавакра-ґіта» двічі згадує соціальну категорію *varṇa*? **Ні.** В обох перевірених електронних транскрипціях:

- **1.5:** `varṇo` — форма `varṇaḥ` (називний однини з сандгі), у сполученні з `viprādiko` стосується категорії, пов'язаної з соціальним становищем;
- **15.14:** `svarṇāt` — відмінкова форма **іншої леми** `svarṇa` («золото»), у зіставленні прикрас із матеріалом, з якого їх виготовлено. Букви `varṇ` у середині цього слова **не є** окремим вживанням `varṇa`.

Простий пошук `"varṇ" in text` не знає морфемних меж. Контекст і межа слова ліворуч від `varṇ` усувають **цей конкретний** хибнопозитивний результат. Це **не універсальна санскритська лематизація**: сандгі може зливати слова, як `āśramānāśramaṃ` нижче.

## Що саме пораховано

| Пошук по основних віршах | SARIT | GRETIL | Наукове значення |
| --- | --- | --- | --- |
| Будь-яке входження підрядка `varṇ` | **1.5, 15.14** | **1.5, 15.14** | Два графічні збіги, один із них хибнопозитивний для леми `varṇa` |
| `varṇ` з межею слова ліворуч | **1.5** | **1.5** | У цьому корпусі усуває `svarṇāt` із 15.14; без повного морфологічного аналізу |
| Будь-яке входження підрядка `āśram` | **1.5, 12.5** | **1.5, 12.5** | **Не** число окремих словоформ: у 12.5 є злитий запис |

Вірш **1.5** має `nāśramī` — заперечення ознаки особи, пов'язаної з *āśrama*. Вірш **12.5** має `āśramānāśramaṃ` — сполучення основи *āśrama* з *anāśrama* в одному записі. Коректну межу й синтаксичний зв'язок цього складного виразу слід залишити для незалежного філологічного рецензування. Механічний підрахунок входжень `āśram` не встановлює, скільки в тексті лем або самостійних слів.

Інший уже підготовлений розбір [1.5](../verse-1-5-ashrama-varna.md) стосується соціально-філософського змісту цього вірша. Наявні картки [12.5](../../../editorial/cards/12.5.json) та [15.14](../../../editorial/cards/15.14.json) — окремі чернетки; цей документ **не змінює** їх і не підвищує їхнього статусу.

## Відтворення офлайн

Збережіть **саме зазначені вище піновані XML-файли** у локальні `/tmp/astavakragita.xml` (SARIT) та `/tmp/sa_aSTAvakragItA.xml` (GRETIL). Виконайте Python 3 лише зі стандартною бібліотекою:

```python
from pathlib import Path
from xml.etree import ElementTree as ET
import re

XML_ID = "{http://www.w3.org/XML/1998/namespace}id"
SOURCES = {
    "SARIT": (Path("/tmp/astavakragita.xml"), "verse_"),
    "GRETIL": (Path("/tmp/sa_aSTAvakragItA.xml"), "Avg_"),
}
for name, (filename, prefix) in SOURCES.items():
    root = ET.parse(filename).getroot()
    records = {}
    for node in root.iter():
        if node.tag.rsplit("}", 1)[-1] != "lg":
            continue
        identifier = node.get(XML_ID, "")
        if identifier.startswith(prefix):
            verse_id = identifier[len(prefix):]
            assert verse_id not in records, (name, verse_id)
            records[verse_id] = " ".join(node.itertext())

    naive = sorted(v for v, text in records.items() if "varṇ" in text)
    left_boundary = sorted(
        v for v, text in records.items()
        if re.search(r"(?<!\w)varṇ", text, flags=re.UNICODE)
    )
    ashrama = sorted(v for v, text in records.items() if "āśram" in text)
    print(name, "підрядок:", naive, "ліва межа:", left_boundary,
          "āśram:", ashrama)

    assert naive == ["1.5", "15.14"]
    assert left_boundary == ["1.5"]
    assert ashrama == ["1.5", "12.5"]
```

Для перевірки філологічної природи збігу недостатньо самих трьох множин. Потрібно прочитати контекст `varṇo` у 1.5 і `svarṇāt` у 15.14. Навіть пошук із лівою межею слова може **пропускати або спотворювати** інші санскритські леми через сандгі, складні слова та відмінності транскрипції. Результат вище перевірено для цих двох конкретних цифрових файлів, а не для всіх можливих рукописів, редакцій чи транслітерацій.
