## Картка 1.6 — діяч, споживач і полярні оцінки

| Поле | Дані |
| --- | --- |
| ID | **1.6** |
| Джерело A | GRETIL: `Avg_1.6`, `vibho` |
| Джерело B | SARIT: `verse_1.6`, `bibho` |
| IAST — опорні слова | `dharma-adharmau`, `sukhaṃ duḥkhaṃ`, `mānasāni`, `na kartāsi na bhoktāsi`, `sarvadā` |
| Граматика | `dharma-adharmau` — протиставлення «належне/неналежне» (форма двоїни); `mānasāni` — множинний середній рід, «належні до розуму»; `kartā` — діяч, `bhoktā` — той, хто переживає/споживає наслідки; `na` заперечує обидві ролі. |
| Дослівний сенс | Твердження про моральні оцінки, радість і страждання як феномени розуму переходить до заперечення абсолютного ототожнення співрозмовника з діячем і споживачем. |
| Редакторська пропозиція | Не перетворювати «ти не діяч» на соціальну чи юридичну тезу, начебто людина не відповідає за вчинки. У контексті діалогу це онтологічне висловлювання про Я; коментар повинен відрізняти його від етичного припису. |
| Різниця свідків | **`vibho` / `bibho`** у звертанні. Причина розходження **не встановлена**; не оголошувати його автентичним варіантом рукопису, поки не перевірено друковані джерела. |
| Статус | Два електронні записи перевірено; морфологічне та філософське тлумачення потребує незалежної рецензії. |

## Картка 1.7 — один свідок, не «самотній спостерігач»

| Поле | Дані |
| --- | --- |
| ID | **1.7** |
| Джерело A/B | GRETIL `Avg_1.7`; SARIT `verse_1.7` |
| IAST — опорні слова | `eko draṣṭāsi sarvasya`; `muktaprāyo 'si`; `draṣṭāraṃ paśyasītaram` |
| Граматика | `ekaḥ` у контексті `draṣṭā` стосується єдності/єдиності свідка; `sarvasya` — родовий відмінок «всього»; `paśyasi` — «ти бачиш/вважаєш»; `itaram` — «іншим». |
| Дослівний сенс | Співрозмовник названий єдиним свідком усього. «Поневолення» пов'язане з тим, що свідка вважають кимось іншим. |
| Редакторська пропозиція | **«Єдиний свідок»** точніше передає `eka`, ніж «самотній спостерігач»: останній додає психологічний мотив ізоляції, не засвідчений самим словом. Вибір «свідок»/«спостерігач» узгоджувати з `sākṣin` у 1.3. |
| Різночитання | У порівнюваних електронних рядках істотних відмінностей у цій конструкції не встановлено; пунктуація і видимі межі слів різняться. |
| Статус | Чернетка для рецензії, не затверджений переклад. |

## Картка 1.8 — отрута думки «я дію» і протиотрута віри

| Поле | Дані |
| --- | --- |
| ID | **1.8** |
| Джерело A/B | GRETIL `Avg_1.8`; SARIT `verse_1.8` |
| IAST — опорні слова | `ahaṃ kartā iti`; `ahi-daṃśitaḥ`; `na ahaṃ kartā iti`; `viśvāsa-amṛtam`; `pītvā` |
| Граматика | `iti` позначає зміст думки; `ahi` — змія, `daṃśitaḥ` — укушений; `amṛta` — нектар/амрита, `pītvā` — дієприслівникова форма «випивши». |
| Дослівний сенс | Ототожнення з діячем змальовано як укус змії, а певність «я не [абсолютний] діяч» — як прийняття нектару. Метафора продовжує образи отрути/нектару з 1.2. |
| Редакторська пропозиція | Зберегти **обидві** паралельні конструкції «я — діяч» / «я не діяч», не зводити їх до механічного «нічого не роби». Складне слово біля образу великої чорної змії потребує окремого граматичного розбору, а не довільних епітетів. |
| Різночитання | Словесний ланцюжок загалом збігається; SARIT використовує інші межі слів / знаки сандгі. |
| Статус | Чернетка, не рецензовано. |

## Картка 1.9 — метафора вогню впевненості

| Поле | Дані |
| --- | --- |
| ID | **1.9** |
| Джерело A | GRETIL `Avg_1.9`, `vītasokaḥ` |
| Джерело B | SARIT `verse_1.9`, `vītaśokaḥ` |
| IAST — опорні слова | `eko viśuddhabodho 'ham`; `niścaya-vahninā`; `prajvālya`; `ajñāna-gahanam`; `vītaśokaḥ` |
| Граматика | `niścaya` — певність/переконаність, `vahni` — вогонь, `-nā` — інструментальна форма; `prajvālya` — дієприслівникова форма від «запалити/спалити»; `ajñāna` — незнання, `gahana` — хащі/густина. |
| Дослівний сенс | В образі вогню певності спалюється хаща невідання, після чого адресата закликають бути вільним від скорботи. Це метафора пізнання, а не інструкція з фізичного спалювання. |
| Різниця свідків | Графічна різниця **`vītasokaḥ` (GRETIL) / `vītaśokaḥ` (SARIT)**. Не робити висновків про рукописну традицію лише з цього; потрібна перевірка друкованих видань та умов транскрипції. |
| Статус | Чернетка, перевірено електронні послідовності, не виконано рукописної колації. |

## Картка 1.10 — не переплутати мотузку і змію з онтологічним «творенням»

| Поле | Дані |
| --- | --- |
| ID | **1.10** |
| Джерело A/B | GRETIL `Avg_1.10`; SARIT `verse_1.10` |
| IAST — опорні слова | `viśvam idaṃ bhāti`; `kalpitaṃ`; `rajju-sarpavat`; `ānanda-paramānandaḥ`; `sa bodhas tvaṃ`; `sukhaṃ cara` |
| Граматика | `yatra` вводить місце/підставу явлення; `rajju` — мотузка, `sarpa` — змія, `-vat` — порівняння; `kalpita` може означати уявлене/приписане; `cara` — наказова форма «рухайся/живи». |
| Дослівний сенс | Світ описано як явище в усвідомленні, подібне до помилкового сприйняття змії в мотузці. Вислів спрямовує на розрізнення явлення та основи явлення; не доводить фізичної тези, ніби думки матеріально «створюють Всесвіт». |
| Редакторська пропозиція | Зберегти явне порівняння **«змія в мотузці»** і відділити пояснення принципу помилкового приписування від власне рядка вірша. `sukhaṃ cara` не слід без примітки підміняти виключно «будь щасливий»: форма містить образ способу життя/руху. |
| Різночитання | У GRETIL і SARIT зафіксовано `sukhaṃ cara`. Відмінні читання, які інколи трапляються в інших електронних публікаціях, тут **не встановлені як варіанти двох перевірених свідків**. |
| Статус | Власний аналіз, потрібна редакційна та санскритологічна перевірка. |
