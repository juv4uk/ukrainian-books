# Українська бібліотека — власні переклади та дослідження

Незалежний український проєкт філологічних досліджень, власних перекладів і майбутніх науково-коментованих видань. Перший пріоритет — **«Аштавакра-ґіта»**.

Ми **не є форком** [історичного репозиторію `livros`](https://github.com/juv4uk/livros): чужі книжки, PDF, LaTeX, переклади чи історію комітів не переносимо. [Політика співпраці без імпорту текстів](docs/LIVROS_REFERENCE_POLICY.md).

## Джерела та наукова звірка

- [Реєстр усіх 20 глав](research/ashtavakra/registry-20-chapters.md) і [порозділова CSV-таблиця](research/ashtavakra/registry-20-chapters.csv): **298 унікальних пронумерованих позицій і в GRETIL, і в SARIT**. Особливості цифрової XML-розмітки SARIT (1.1, 18.95/18.96) **не означають відсутності санскритських віршів**. Історична колонка `SARIT_віршів` у CSV обліковує `<lg xml:id>`, а не всі пронумеровані позиції.
- [Карта розходжень GRETIL/SARIT](research/ashtavakra/variant-map.md), [розбір кандидатів](research/ashtavakra/variant-shortlist.md), [перевірка третього цифрового свідка](research/ashtavakra/third-witness.md). **Різниця електронних транскрипцій ще не доводить рукописного різночитання.**
- [Чому Sahu (2024) називає 285 шлок, а корпуси містять 298 позицій?](research/ashtavakra/studies/verse-count-285-vs-298.md) — окремий дослідницький розбір, без припущення про недоведене інше видання.
- [Бібліографія](research/ashtavakra/bibliography.md) та [редакторський словник](editorial/GLOSSARY.md). Цифровий свідок **не є автоматично критичним виданням**.

## Як долучитися і перевірити

Читайте [правила співпраці](CONTRIBUTING.md), [план робіт](tasks/ROADMAP.md) і [початкову інструкцію](docs/START.md). Перед змінами звіряйте Issues, PR та CLAIM інших агентів. Кожна завершена зміна проходить окремий PR, перевірки і незалежний перегляд.

```sh
python3 scripts/check_project.py
python3 scripts/check_editorial_cards.py
python3 scripts/check_verse_registry.py
python3 scripts/check_duplicate_cards.py --strict
python3 scripts/check_provenance.py
```

GitHub Actions повторюють застосовні перевірки. [Складання видань](.github/workflows/build-books.yml) не доводить створення PDF/EPUB без фактичного успішного запуску, артефакту та підтверджених прав. [Контрольний список захисту `main`](docs/MAIN_PROTECTION_CHECKLIST.md) також **не вмикає захист автоматично**.

**Стан:** український корпус та науковий апарат розвиваються; остаточне академічне видання потребує перевірки першоджерел, прав та незалежних редакторських висновків.
