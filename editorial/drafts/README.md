# Чернеткові книжкові тексти «Аштавакра-ґіти»

Це **робочі українські переклади з редакторських карток**, не рецензоване й не дозволене до публікації видання. Розділи та зміст перенесено сюди без зміни їхнього тексту з [PR #521](https://github.com/juv4uk/ukrainian-books/pull/521), щоб не підміняти вимоги `scripts/check_provenance.py`.

У заголовках перенесених розділів згадано `PROVENANCE.md`: мається на увазі [паспорт підготовлюваного видання](../../books/ashtavakra-gita/PROVENANCE.md), який **не підтверджує** незалежного рецензування, юридичного дозволу на випуск або готовності до PDF/EPUB. Публікувати ці тексти як готове видання можна лише після перевірки прав, рецензування і передбаченого проєктом приймання.

[Чернетковий зміст](ZMIST.md) показує пропуски й наявність матеріалу; він не є твердженням про повноту чи якість.
