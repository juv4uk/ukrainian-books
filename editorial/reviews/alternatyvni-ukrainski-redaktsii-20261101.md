# Збережені альтернативні українські редакції із закритих PR

**Це редакторський архів, не канонічний текст книги.** 1 листопада 2026 року кілька старих Draft PR було закрито **без злиття**. Порівняння точного HEAD кожного такого PR з чинним `main` показало, що в них збереглися окремі власні українські варіанти перекладу. Нижче вони відтворені **дослівно**, без художньої переробки. Це вибірка п'яти перевірених випадків, не облік усіх закритих PR.

**Межі:** жодну канонічну картку, науковий чи поетичний том не переписано. Тут зберігається лише поле `ukrainian_translation` із власних карток старих PR — не сторонні санскритські транскрипції чи коментарі. Альтернативи **не є незалежно рецензованими або правово погодженими виданнями**. Залишено посилання на PR та його незмінний SHA для відтворення.

## Подальша редакторська процедура

1. Перевірити кожну альтернативу за санскритською граматикою та цифровими свідками з чинної картки; різні переклади самі собою не доводять текстового різночитання.
2. У разі прийняття редакції — окремий CLAIM, обґрунтований PR, перевірка Markdown/LaTeX, CI та прав. Не переносити старий JSON поверх сучасного без аналізу зміни структури.
3. «ВОЛЬНІСТЬ» лишається незмінною; закриття PR без merge не означає, що його унікальна редакція вже включена до канонічної книги.
