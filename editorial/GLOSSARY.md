# Редакційний словник

| Санскрит | Робочий український відповідник | Застереження |
| --- | --- | --- |
| *ātman* | Я / істинне Я | Не тотожне повсякденному его |
| *cit* | свідомість / усвідомлення | Значення визначає контекст |
| *sākṣin* | свідок | Філософський, а не судовий образ |
| *mukti* | звільнення / визволення | Обрати послідовний термін у виданні |
| *vairāgya* | неприв'язаність | Не підміняти байдужістю |
| *toṣa* | вдоволеність | Важлива пропущена чеснота у посередньому перекладі 1.2 |
| *āśrama* | стадія / стан життя | Не зводити до «обов'язків» |
| *varṇa* | суспільна категорія | Відрізняти від життєвого стану |

Робочі відповідники підлягають санскритологічній і літературній перевірці.
