# Правила спільної роботи

1. Створіть Issue з точними номерами віршів, файлами, джерелами, правами й критеріями готовності.
2. Поставте **CLAIM** (виконавець, обсяг, файли, дата) до початку редагування; не перехоплюйте активний CLAIM.
3. Один PR — одна робота: переклад, коментар, бібліографія або CI; не змішуйте їх.
4. Не переносіть чужих повних книг, сучасних перекладів або PDF без достатньої правової підстави та доказів у `PROVENANCE.md`.
5. Зіставляйте GRETIL і SARIT, зазначайте різночитання; не називайте електронні корпуси критичними виданнями.
6. Документація, задачі та коментарі українською. Ідентифікатори програм допускаються у стандартному форматі.
7. Зливайте до `main` тільки після зелених перевірок, перегляду diff, редакторського рецензування і перевірки прав.
8. Ліцензія одна — **ВОЛЬНІСТЬ**. `LICENSE` та `VOLNOST.md` повинні бути буквально однаковими.
